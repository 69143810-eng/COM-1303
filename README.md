## 1.Git คืออะไร
ระบบควบคุมเวอร์ชันแบบกระจายศูนย์ (Distributed Version Control System)
ที่ใช้สำหรับติดตามการเปลี่ยนแปลงของไฟล์และซอร์สโค้ดในโปรเจกต์


## 2.การทำงานของเว็บไซต์ทำงานอย่างไร
การทำงานของเว็บไซต์สรุปเป็น 3 ขั้นตอนหลัก ดังนี้:  


1.ส่งคำขอ (Request): เมื่อคุณพิมพ์ชื่อเว็บ (เช่น google.com) เบราว์เซอร์จะค้นหา "ที่อยู่ IP" แล้วส่งคำขอเปิดหน้าเว็บไปยัง Server (เครื่องคอมพิวเตอร์ที่เก็บไฟล์เว็บไซต์)


2.ส่งข้อมูลกลับ (Response): Server ประมวลผล
  แล้วส่งไฟล์เว็บไซต์กลับมายังเครื่องของคุณ (ประกอบด้วยไฟล์ HTML โครงสร้าง
  CSS ตกแต่งความสวยงาม, และ JavaScript ระบบโต้ตอบ)


3.แสดงผล (Rendering): เบราว์เซอร์ (Chrome, Safari ฯลฯ)
  จะแปลงไฟล์เหล่านั้นออกมาเป็น หน้าตาเว็บไซต์ ให้คุณเห็นและใช้งานได้ทันที

## 3.เว็บไซต์ต่างจากเว็บแอพพลิเคชั่น อย่างไร

เว็บไซต์: เป็นหน้าเว็บที่เน้นการให้ข้อมูลเป็นหลัก

ลักษณะ: ทำงานเร็ว ไม่ซับซ้อน มักไม่มีระบบล็อกอิน (หรือมีแค่ระบบติดต่อทั่วไป)

ตัวอย่าง: เว็บไซต์บริษัท, เว็บข่าว (เช่น Sanook, Thairath), Blog ส่วนตัว, 
        เว็บพอร์ตโฟลิโอ


เว็บแอป: เป็นเว็บโปรแกรมที่สร้างมาเพื่อให้ผู้ใช้ทำกิจกรรมอย่างใดอย่างหนึ่ง

ลักษณะ: ต้องมีการล็อกอินเข้าใช้งาน มีระบบฐานข้อมูลหลังบ้านที่คอยคำนวณและบันทึกข้อมูลอยู่ตลอด          เวลา

ตัวอย่าง: Facebook (โพสต์/แชท), Gmail (รับส่งเมล), Shopee (ซื้อของ/ชำระเงิน), 
Canva (แต่งรูป), Netflix (สตรีมมิ่ง)
