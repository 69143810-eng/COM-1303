## 1.Git คืออะไร
คือระบบควบคุมเวอร์ชันแบบกระจายศูนย์ (Distributed Version Control System - DVCS) ที่ใช้สำหรับติดตามการเปลี่ยนแปลงของซอร์สโค้ดในโปรเจกต์ซอฟต์แวร์ คิดค้นโดย Linus Torvalds ผู้สร้าง Linux เมื่อปี 2005


## 2.การทำงานของเว็บไซต์ทำงานอย่างไร
การทำงานของเว็บไซต์สรุปเป็น 3 ขั้นตอนหลัก ดังนี้:


1.ส่งคำขอ (Request): เมื่อคุณพิมพ์ชื่อเว็บ (เช่น google.com) เบราว์เซอร์จะค้นหา "ที่อยู่ IP" แล้วส่งคำขอเปิดหน้าเว็บไปยัง Server (เครื่องคอมพิวเตอร์ที่เก็บไฟล์เว็บไซต์)


2.ส่งข้อมูลกลับ (Response): Server ประมวลผล
  แล้วส่งไฟล์เว็บไซต์กลับมายังเครื่องของคุณ (ประกอบด้วยไฟล์ HTML โครงสร้าง
  CSS ตกแต่งความสวยงาม, และ JavaScript ระบบโต้ตอบ)


3.แสดงผล (Rendering): เบราว์เซอร์ (Chrome, Safari ฯลฯ)
  จะแปลงไฟล์เหล่านั้นออกมาเป็น หน้าตาเว็บไซต์ ให้คุณเห็นและใช้งานได้ทันที

## 3.เว็บไซต์ต่างจากเว็บแอพพลิเคชั่น อย่างไร

เว็บไซต์: เน้น "อ่าน/ดู" (เหมือนหนังสือออนไลน์ ข้อมูลเหมือนกันทุกคน)

เว็บแอป: เน้น "ทำ/ตอบโต้" (เหมือนโปรแกรม/เครื่องมือ ต้องล็อกอิน ประมวลผลเฉพาะบุคคล)

## 4.ให้สร้างคู่มือการใช้งาน Github
คู่มือ GitHub สรุปย่อใน 4 ขั้นตอนหลัก:

1.เริ่มต้นใช้งาน (Setup)

.สมัครเว็บ GitHub.com + โหลดโปรแกรม Git ใส่เครื่อง

.ตั้งชื่อ/อีเมลใน Terminal:

git config --global user.name "ชื่อคุณ"

git config --global user.email "อีเมลคุณ"

2.เชื่อมต่อโปรเจกต์ (Clone)

.สร้าง Repo บน GitHub แล้วก๊อป URL มาดึงลงเครื่อง:

git clone https://github.com/username/my-project.git

3.วงจรส่งโค้ดขึ้นเว็บ (Daily Workflow)

.เมื่อแก้โค้ดเสร็จแล้ว ให้ทำ 3 คำสั่งนี้เสมอ:

git add .                           # 1. เลือกไฟล์ทั้งหมด

git commit -m "อธิบายสิ่งที่แก้ไข"   # 2. บันทึกประวัติ

git push                            # 3. ส่งขึ้น GitHub

4.ดึงโค้ดล่าสุดลงเครื่อง (Pull)

.ก่อนเริ่มงานทุกครั้ง ให้ดึงโค้ดอัปเดตล่าสุดจากเพื่อน/เซิร์ฟเวอร์:

git pull
